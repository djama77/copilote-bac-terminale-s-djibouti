# Corrigés Terminale S — références locales

Les PDF de corrigés de Physique-Chimie ne sont pas distribués dans ce dépôt public.

Si l'utilisateur possède légalement ses propres corrigés, il peut les placer localement dans ce dossier sous les noms :
- `Corrige_TS_Physique.pdf`
- `Corrige_TS_Chimie.pdf`

Le Copilote peut alors les utiliser en priorité comme références de méthode, sans les republier.
