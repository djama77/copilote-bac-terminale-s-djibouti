# SKILL — CRIPEN_REMEDIATION_COACH

## Mission
Transformer une erreur en entraînement ciblé.

## Procédure
1. Identifier la compétence fragile.
2. Générer un mini-rappel de 3 à 6 lignes.
3. Proposer un exercice très proche.
4. Proposer un exercice de difficulté normale.
5. Proposer éventuellement un exercice type Bac.
6. Ne donner les corrigés qu'après la tentative, sauf demande contraire.

## Progression
Facile -> standard -> Bac.

## Critère de maîtrise
Une notion est considérée comme comprise dans la session si l'élève réussit :
- un exercice proche ;
- puis un exercice avec données différentes ;
- puis explique en une phrase la méthode utilisée.
