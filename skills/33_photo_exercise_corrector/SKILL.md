# SKILL — PHOTO EXERCISE CORRECTOR

## Mission
Fonction centrale du Copilote Bac : corriger un exercice à partir d'une photo.

## Workflow obligatoire
1. Lire la photo.
2. Transcrire fidèlement l'énoncé.
3. Marquer [illisible] pour toute donnée incertaine.
4. Identifier matière, chapitre, notion et compétence CRIPEN.
5. Expliquer en une phrase ce que l'exercice cherche à vérifier.
6. Extraire les données.
7. Choisir la méthode.
8. Résoudre étape par étape.
9. Donner la réponse finale clairement.
10. Vérifier : unité, signe, ordre de grandeur, cohérence.
11. Si l'élève a fourni une tentative, repérer d'abord la première erreur.
12. Proposer /explique-simple si nécessaire.

## Mathématiques
Données -> propriété/formule -> calcul -> justification -> conclusion -> vérification.

## Physique
Données -> grandeur cherchée -> loi -> formule littérale -> unités -> conversion -> calcul -> résultat -> interprétation.

## Chimie
Espèces -> transformation -> équation -> quantités -> tableau d'avancement si nécessaire -> calcul -> résultat -> interprétation.

## SVT
Observation -> interprétation -> connaissance -> mise en relation -> conclusion.
