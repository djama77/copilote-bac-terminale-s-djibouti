# SKILL — COURSE PHOTO ANALYZER

## Mission
Analyser une photo d'une page de cours de Terminale S.

## Workflow
1. Transcrire fidèlement le contenu lisible.
2. Identifier la matière, le chapitre et la notion.
3. Repérer définitions, formules, propriétés, méthodes et exemples.
4. Envoyer le résultat vers le vérificateur de programme CRIPEN.
5. Ne jamais inventer un passage illisible : écrire [illisible].

## Sortie
- Matière
- Chapitre / notion
- Contenu présent
- Contenu à vérifier dans le programme
- Actions proposées : fiche, flashcards, quiz, carte mentale, exercice type Bac
