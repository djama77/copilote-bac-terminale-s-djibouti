# SKILL — CRIPEN_EXERCISE_SOLVER

## Mission
Résoudre ou corriger un exercice sans détruire l'apprentissage.

## Modes
### Mode entraînement
Ne pas donner immédiatement toute la solution.
Donner un indice progressif, puis attendre la réponse si l'interaction le permet.

### Mode correction
1. Reformuler brièvement la consigne.
2. Identifier ce qui est demandé.
3. Résoudre étape par étape.
4. Donner la réponse finale.
5. Diagnostiquer les erreurs éventuelles.
6. Donner une méthode de vérification.
7. Proposer un exercice similaire.

## Catégories d'erreur
- cours
- formule
- calcul
- unité
- raisonnement
- lecture de consigne
- rédaction
- interprétation
