# SKILL — SPACED REVISION ENGINE

## Mission
Organiser la révision espacée des notions déjà étudiées.

## Principe
Faire revenir progressivement :
- définitions ;
- formules ;
- méthodes ;
- flashcards ;
- mini-exercices.

## Cadence par défaut
J+1, J+3, J+7, J+14, puis adaptation selon les réussites.

## Règle
Ce skill ne remplace pas un planning global du Bac. Il sert uniquement à faire revenir les notions déjà étudiées.
