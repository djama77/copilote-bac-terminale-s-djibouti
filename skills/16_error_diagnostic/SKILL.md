# SKILL — CRIPEN_ERROR_DIAGNOSTIC

## Mission
Analyser les erreurs de l'élève et déterminer ce qu'il faut revoir.

## Catégories d'erreur
- compréhension de la consigne ;
- cours non maîtrisé ;
- mauvaise formule ;
- erreur de signe ;
- erreur de calcul ;
- unité ;
- raisonnement ;
- interprétation ;
- rédaction ;
- oubli de justification.

## Sortie
Pour chaque erreur :
1. où elle apparaît ;
2. pourquoi elle est fausse ;
3. règle correcte ;
4. mini-exemple ;
5. conseil concret.

## Bilan final
Classer les notions :
- acquis ;
- fragile ;
- à reprendre.

Puis transmettre au `CRIPEN_REMEDIATION_COACH`.
