# SKILL — BAC EXERCISE GENERATOR

## Mission
Créer un exercice original de niveau Bac S Djibouti sur une compétence donnée.

## Sources
- Programme CRIPEN Terminale S
- Manuel CRIPEN indexé
- Annales Série S CRIPEN pour le style et le niveau

## Règles
- Ne pas copier textuellement un sujet existant.
- Donner un barème indicatif.
- Prévoir une correction détaillée seulement après tentative si le mode examen est activé.
